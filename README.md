# Fomina.Designs — концепт

Окремий концепт сайту, зроблений за мотивами [primesec.ai](https://www.primesec.ai/).
**Не замінює** робочий сайт у репозиторії `fominadesigns.github.io` — це паралельний варіант.

## У чому ідея

Головна відмінність від нинішнього сайту — **світла вага заголовків**.
На нинішньому вона 800, тут 200–300.

Причина: три дорогі B2B-сайти поспіль тримають легкі заголовки —
Prime Security 400, DayNight 500. Важке накреслення читається як розпродаж,
легке — як послуга, що коштує грошей.

## Механіки

- **Вкладки за нішами** в першому екрані. Перемикання змінює заголовок,
  текст і зображення; решта екрана лишається на місці
- **Закріплена секція** з горизонтальним рухом кроків роботи
- Тонка сітка на тлі першого екрана

Обидві механіки написані з нуля. У primesec.ai для цього стоять
GSAP, ScrollTrigger, SplitText, Lenis, Swiper і jQuery — тут нічого з цього немає.

## Зображення
- `niche-proto.webp` — паперові прототипи, ніша консалтингу
- `niche-paper.webp` — макро стосу паперу, ніша медицини
- `niche-arch.webp` — бетон знизу з жовтим променем, ніша інтерʼєру

Згенеровано Recraft V4.1 із заданою палітрою #F9FE4A / #1A1A1A / #F5F5F0.

Прев'ю кейсів нахилені в просторі засобами CSS, а не картинкою:
справжні скріншоти лишаються чіткими на будь-якому екрані.
- Ціни в секції «Ціна» — цифри поки орієнтовні
